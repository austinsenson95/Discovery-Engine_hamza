# Branding Research: DISCOVERY ENGINE

## Inspiration Site Analysis: https://my-freedom-roadmap.lovable.app/

### Visual Identity
- **Background**: Clean white (#FFFFFF) with subtle grid line patterns
- **Primary Accent**: Vibrant orange (#F05A28 / #FF5500) for CTAs, highlights, italic emphasis text
- **Text Colors**: Deep black (#0A0A0A) for headlines, medium gray (#4A4A4A) for body
- **Secondary Badges**: Black (#0A0A0A) pill badges with white text for labels
- **Success/Positive**: Green checkmarks, green for revenue indicators
- **Cards**: White with subtle borders, minimal shadows

### Typography
- **Headlines**: Bold serif font (DM Serif Display / Playfair Display style), very large sizes (48-72px), black
- **Emphasis within headlines**: Italic serif in orange color for key phrases
- **Body text**: Clean sans-serif (Inter / system-ui), 16px, gray
- **Labels/Badges**: Uppercase, wide letter-spacing, small size (11-12px)
- **CTA Buttons**: Sans-serif, medium weight, white text on orange

### Layout Patterns
- **Hero**: Full-width, left-aligned content, massive serif headline with orange italic emphasis, orange CTA pill button
- **Spacing**: Very generous whitespace, airy feel
- **Badges**: Pill-shaped, uppercase labels ("FREE - PERSONALIZED - 24-HOUR DELIVERY")
- **Cards**: Clean, subtle borders, not heavy shadows
- **Dark sections**: Occasional dark (#0A0A0A) sections for contrast with white text

### CTA Styling
- Primary: Orange pill button with white text, arrow icon, hover scale effect
- Secondary: Black pill badge with white text
- Links: Underline on hover

### Logo/Brand Element
- Orange diamond/rhombus shape as brand mark
- Clean wordmark next to icon

### Applied to DISCOVERY ENGINE
- Replace purple from original spec with orange (#F05A28)
- Keep green (#059669) for success states, revenue, progress
- Use black (#0A0A0A) for sidebar, top nav, headings
- White backgrounds throughout
- Serif headlines for major titles
- Orange italic emphasis for key words in headlines
- Pill-shaped CTAs in orange
- Clean, spacious layouts with generous whitespace

## Feature Requirements (from spec)
1. **Dashboard**: Welcome greeting, credit display (100 credits), language selector, blueprint wizard CTA card, progress tracking
2. **4-Step Wizard**: Niche Discovery -> Audience Mapping -> Program Builder (3 sub-steps) -> Roadmap & PDF
3. **Sidebar Navigation**: Logo + tagline, Program section (Dashboard, Blueprint), My Stuff section (Journey, Profile), User card at bottom
4. **Credit System**: 100 credits start, deductions per AI generation
5. **PDF Export**: 8-page blueprint PDF generation
6. **My Journey**: Progress tracking, gamified visualization
7. **Profile**: User settings, logout

## Dummy Data Requirements
All AI-generated content should use realistic dummy data:
- 2-3 niche recommendations per generation
- Detailed persona profiles
- 3 program name suggestions
- Pricing strategy with revenue projections
- Complete roadmap timeline
